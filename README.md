# Starscream

***

***Sentiment Analysis CLI using transformers***

# Summary

*Starscream* is a CLI built with [Typer](https://typer.tiangolo.com/) that parses the contents of a file for sentiment analysis. It uses [DistilBERT](https://huggingface.co/lxyuan/distilbert-base-multilingual-cased-sentiments-student) for that.

# Supported File Types

- [audio](https://www.iana.org/assignments/media-types/media-types.xhtml#audio).
- [text](https://www.iana.org/assignments/media-types/media-types.xhtml#text).

# Usage

```
starscream FILE --output FILE --show --title TEXT
```
